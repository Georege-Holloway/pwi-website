Photography goes here.

Rules, no exceptions:

1. Lowercase filenames, hyphens only. No spaces, no commas, no capitals.
   Netlify is case sensitive and the old WordPress uploads folder is full
   of filenames that will break.
2. PWI's own work only. No stock photography, and nothing copied across
   from the old site until it is confirmed as theirs. See OPEN-4.
3. WebP, with width and height set on every img tag to stop layout shift.
4. Alt text describes the furniture, not the photograph.

Naming: project-slug-01.webp, for example bromley-alcove-units-01.webp

5. Never replace a photo under the same filename. Everything in /images/ is
   served with a one year immutable cache, so returning visitors would keep
   seeing the old one. Give the new photo a new name and update the HTML.
